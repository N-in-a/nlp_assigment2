# Sentiment Classification 

## Project Description
This project focuses on sentiment classification using the Cornell Movie Review Dataset.

The goal is to classify movie reviews into two categories: positive and negative.

## Dataset
The dataset contains 2,000 movie reviews:
- 1,000 positive reviews
- 1,000 negative reviews

## Methods
The project uses three text representations:
- Boolean features
- TF-IDF unigrams
- TF-IDF unigrams and bigrams

The classification models are Logistic Regression models, compared with a majority-class baseline.

## Files
- `notebook.ipynb`: Jupyter notebook containing the code and experiments.
- `report.pdf`: Final project report.
